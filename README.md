# interactive-resume
nteractive 3D office tour resume. Walk through reception to see my projects, skills, education, and contact links. Built with Three.js.

Shahzaib’s Office is an interactive resume. You enter a virtual office, meet the receptionist, and choose a room. Each room opens a section of my resume: Projects, Skills, Education, and Contact.

Features

Guided walk with realistic 3D characters
Four rooms, one per resume section
Full office view from above
Plain resume view for quick reading
Links to GitHub, LinkedIn, and email
Single HTML file with no build step

Tech

Three.js
JavaScript, HTML, CSS
